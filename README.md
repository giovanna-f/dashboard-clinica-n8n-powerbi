# 📊 Dashboard de Clínica com n8n + Power BI

## Sobre o projeto
Desenvolvi um sistema simples para controle de pacientes e faturamento, integrando automação com visualização de dados.

## Tecnologias utilizadas
- n8n (automação e API via webhook)
- Google Sheets (armazenamento de dados)
- Power BI (dashboard interativo)

## Funcionalidades
- Cadastro de pacientes (add)
- Consulta de dados (get)
- Atualização de informações (update)
- Remoção de pacientes (delete)

## Dashboard
O dashboard permite:
- Visualizar faturamento total
- Analisar pacientes por tipo de atendimento
- Identificar pacientes com poucas sessões
- Ver ranking de faturamento por paciente

## Objetivo
Simular um cenário real de negócio, automatizando processos e gerando insights para tomada de decisão.
